# Java-Multithreading-Exercise
I have 2 files CPU.java and Memory.java
In order to run the program, have both files in the same folder. Then Javac CPU.java and Memory.java.
You then java CPU <filename> <timer> to run
The CPU.java class is the main class as it has all the runtime/process creation inside of it and all the instructions on what to do with the instructions from memory.
The Memory.java class is a glorified storage container, as it is able to store and send information to the cpu as needed.
